# term-maze-raycast

Go 版 raycast 风格 3D 迷宫：融合

- [raycast-game](https://github.com/httpspycharmhelpers/raycast-game) — 画面与操作：墙壁 / 天花板 / 地板 / 俯仰 / 视高 / 视野的 DDA 光线投射渲染，按键布局完全一致
- [term-maze-3d](https://github.com/Yadav106/termi-maze-3d) — 迷宫玩法：随机迷宫、自由探索

用 Go 实现，零第三方图像库，仅依赖 `eiannone/keyboard`（按键）与 `x/sys/unix`（终端尺寸）。

## 画面

- 墙壁使用 DDA 光线投射 + 边缘描边：竖直边 `|`、水平边 `_`（俯仰时 `/` `\`）、转角 `·`
- 天花板留空，地板用 `.` 填充，地平线随俯仰 / 视高偏移
- 画面自适应终端尺寸：终端缩小或放大，游戏画面跟着缩放，不会出现乱码

## 迷宫

- 巨型随机迷宫，默认 1000×1000，递归回溯生成，**所有通路互相连通**，绝不封死道路、没有孤岛
- 生成后再随机拆墙（braiding）打通大量回环，随便逛都不会被堵住
- 无出口、无胜利画面，纯自由探索；玩家出生点固定在迷宫左上角

## 性能

- 生成提速：一次开传奇数格棋盘空间，命中率恒定，大尺寸迷宫数百毫秒内完成
- 渲染提速：列缓冲 / 行缓冲 / 帧缓冲跨帧复用，零每帧分配；光线给 512 步上限防长走廊卡顿
- 帧率：输入以 ~60Hz 节拍更新（手感不变），画面**增量重绘**、上限约 40fps —— 只在内容变化时才向终端发送该行，画面静止时一字节都不写，终端不再被每秒数百 KB 整屏刷新淹没，画面稳且顺（状态行只保留开机按键提示与「小地图开/关」「视野」等瞬时信息，不显示 FPS/坐标）
- 关于“硬件加速”：终端游戏由终端自身（GPU 加速的文本渲染）绘制画面，游戏只需喂字节流；Termux 仅提供软件 GL（mesa/swrast），真用 GPU 需改写成原生窗口 App，对 ASCII 光线投射无实际收益，故不采用
- 画面稳定：终端尺寸每 100ms 采样一次并保持稳定，弹出软键盘/瞬时抖动不会导致画面来回跳动；尺寸真正变化时清屏一次，不乱码
- 按键：`1` 右转、`3` 左转
- 移动/转向即时响应：每按一次键立刻走一步（按住可连续移动），松开后做 250ms 的平滑滑动衔接，不依赖终端按键自动重复，安卓/Termux 上也顺滑
- 开局通道固定打通：出生点北、东两侧始终有三条可行走路径，不会开局顶着墙
- 退出（`q` 或 Ctrl-C）会完整恢复终端回显与行模式，退出后照常输入
- 小地图为玩家周围区域的局部视图（占用屏幕左上的 1/4），成本与迷宫大小无关

## 命令终端 `/`

按 `/` 进入底部悬浮的命令行（收起时约占屏幕 1/3）：输入命令、回车执行，`↑`/`↓` 翻命令历史，输出区用 **`PgUp`/`PgDn` 或 `Ctrl+U`/`Ctrl+D` 滚动**（底部状态行会显示可见范围），`ESC` 返回游戏。动画期间不节流、缓动滑入/滑出，收放平滑。同样支持管道与逻辑连接：`|`（管道）、`&&`/`||`、`;`、单/双引号与反斜杠转义，结构如 sh。**命令只对本游戏内置命令生效**，外部命令一律拒绝并提示未知命令（用 `help` 查看全部可用命令）。

| 命令 | 功能 |
| --- | --- |
| help | 显示全部命令帮助 |
| clear | 清空命令历史 |
| where | 位置 / 楼层 / 朝向 / 俯仰 / 高度 / 视野 |
| home | 回出生点 |
| tp x y | 传送到指定坐标（墙与越界会拒绝） |
| seed | 显示当前地图种子 |
| fov [值\|wide\|normal\|+\|-] | 视野 0.5~5，默认 1 |
| height [值\|high\|low\|ground\|+\|-] | 视高 -5~5，默认 0 |
| reset | 重置俯仰与视高 |
| spin [on\|off] | 视角自动旋转（游戏内任意键停止） |
| flip | 上下翻转视角 |
| party | 轮换墙体 ASCII 样式 |
| floorinfo | 当前楼层信息 |
| space\|space close | 200×200 平地模式 / 返回迷宫 |
| door [x y\|open\|close [all]\|list] | 放门 / 开合 / 列出（小地图 D，关门挡路） |
| bookmark [名] | 标记当前位置 |
| goto [名] | 传送到书签（跨楼层会重建该楼层） |
| elevator [楼层\|home\|list] | 电梯换层，种子固定可重现 |
| edit / edit off | 进入/退出编辑模式（Q 退出） |
| img load <文件> \[x y\] | 贴 ASCII 图片到墙面（缺省贴面前墙） |
| img list / remove <id> | 查看 / 卸载贴图 |
| video play <文件> \[x y\] | 墙面播放 ASCII 视频（帧之间用 `---` 行分隔） |
| video stop / list / remove <id> | 停止 / 查看 / 卸载视频 |
| save [名] | 存为 `~/名.rmap`（RAMAP，含楼层/玩家/门/地图） |
| load [名] | 载入 `~/名.rmap` |
| file <路径> | 识别文件：本游戏存档 / ELF / 未知 |

编辑模式按键：`2/8/4/6` 或方向键移动光标、`0`空地 `1`墙 `空格`切换、`D`放门、`G`抓取、`P`放置、`Q`退出。`where | seed` 等内置命令可参与管道；`save smoke && file smoke.rmap` 同级联执行。存档只写入 `~` 目录，**不执行任何外部命令**。

游戏内按 `空格` 跳跃（抛物线带重力，跳跃中不可再起跳）。地图生成时约 **9% 的墙**会随机变成彩蛋墙：每面墙随机从十余种形状族（实心/环形菱形、圆、方框、十字、沙漏、四角、X 斜带等）抽取一个**严格左右+上下对称**的 8×8 像素画，用 ASCII 特殊字符（`& ; ~ % / = $ ^ ! * ?`）直接画在墙面上；每次重建地图（`reset`/`elevator`）图案都会重新随机，且随迷宫种子可重现。彩蛋墙不阻挡任何操作，小地图显示 `%`。贴图与视频以 ASCII 直接呈现在墙面上（贴图按墙面水平位置采样逐字符映射），小地图分别显示 `I` / `V`。

## 构建运行

```bash
# Termux
pkg install golang
cd term-maze-raycast
go build -o term-maze-raycast .
./term-maze-raycast            # 默认 1000×1000
./term-maze-raycast 600        # 生成 601×601（自动归一为奇数）
./term-maze-raycast 2000      # 更大尺寸
```

小地图中：四周用 `|` 围边、`#` 墙壁、`P` 玩家、空格空地（显示玩家周围区域，占屏幕左上的 1/4）。
